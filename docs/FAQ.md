
**Are ALL Logic Apps Connectors supported?**

Our goal is to support all connectors by public preview. 
Currently 70+ connectors covering Microsoft Services are supported.

**What languages are supported?**

Currently C# and TypeScript/JavaScript(Isomorphic) are supported. The plan is to support all the Azure Functions supported languages. 

**Are Triggers supported?**

NO

**What is the cost of private preview?**

Currently there is no billing for private preview but it is heavily throttled to avoid abuse. 
50 calls per minute.

**Where do i report issues?**

Please use this repo for issues. Create a github issue.
